# FNSPID results (Tier C)

Created by `Tier_C_FNSPID.ipynb`. Source: FNSPID, Nasdaq news file (Dong et al., 2024).

- `fnspid_rows_per_year.csv` / `.png`: headlines per year
- `fnspid_rows_per_ticker.csv`: headlines per ticker
- `fnspid_empty_per_column.csv`: empty values per column
- `fnspid_dedup_counts.csv`: 15,549,299 rows read → 5,541,739 clean headlines

The full cleaned data (`fnspid_clean.parquet`) is too large for GitHub and is kept in Google Drive.
